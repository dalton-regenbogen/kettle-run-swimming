# Archive

Earlier experiments and planning notes, kept for reference during the redesign.
Nothing in this folder is built or published.

- `index-old.html`, `index-alt.html`, `index-merged.html` — earlier homepage versions/experiments.
- `random.html` — scratch important-dates markup.
- `homepage-dark/` — the dark homepage study (HTML, CSS source and compiled CSS, JS).
- `docs/` — the earlier project review and brief.

These files were moved here from the project root, so their relative links (`./css/…`, `./assets/…`)
no longer resolve and they won't display correctly if opened directly. To view one as it was,
check out commit `5e282ad` (e.g. `git switch --detach 5e282ad`, then `git switch rebuild` to return).
